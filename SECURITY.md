# Security Policy

Capture processes private journal text and local credentials. Do not report exposed tokens, authentication bypasses, or data-loss vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/gino001655/Capture/security/advisories/new). Include affected versions, reproduction steps, and whether real personal data may have been exposed. Revoke any credential that was accidentally shared; deleting it from the latest commit does not remove it from Git history.

Only the latest source revision is actively maintained. This personal project does not currently promise a response or patch timeline.
