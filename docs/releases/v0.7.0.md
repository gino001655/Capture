# Personal Capture v0.7.0

Release status: local candidate; this is not the public v1 release.

## Highlights

- Explicit Journal `續` content can be appended as unchecked items to one fixed Heptabase Todo card after normal Journal delivery succeeds.
- Todo delivery has its own lease, retry state, and stable marker, so it does not weaken Journal delivery or blindly duplicate a successful append.
- Optional native Windows reminders surface recent `續` items around 20:00 Taipei and add a recent-seven-day review on Sunday.
- An installed iPhone PWA can opt into equivalent Web Push reminders through a Vercel cron and VAPID keys, with a privacy toggle for notification text.

## Safe defaults

- Todo delivery, Windows notifications, and phone notifications remain off until individually enabled.
- Existing delivered records are not backfilled into Todo. Only newly delivered records with an explicit non-empty `續` enter the Todo queue.
- Capture only appends to the Todo card. Completing, editing, or deleting an item stays entirely under the user's control in Heptabase.
- Web Push private keys remain deployment secrets and are never committed.

## Verification evidence

- Automated verification is recorded in the implementation handoff; production Heptabase append, Windows notification presentation, iPhone subscription, and scheduled Vercel delivery still require manual smoke tests.

## Known limitations

- Vercel Hobby cron timing is approximate rather than an exact 20:00 alarm.
- The Windows worker must be running for native reminders and Todo appends.
- Reminders summarize delivered Journal data, not the live checked/unchecked state of the Heptabase Todo card.
