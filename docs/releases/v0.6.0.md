# Personal Capture v0.6.0

Release status: candidate; do not publish until the manual checklist is complete.

## Highlights

- Desktop Journal, English, Workout, Food, and Worker Status can be operated without a mouse using directional focus, Enter, Escape, and Tab fallback.
- Historical Workout navigation opens the selected date and session instead of today's editor.
- Long Workout and Food pages scroll the focused control into view and support normal wheel/pad scrolling without a visible scrollbar.
- Journal delivery can optionally organize deterministic source Markdown through the locally signed-in Codex CLI before appending to Heptabase.
- Eligible past English documents can optionally become structured `English_AI` notes in `English` through AnkiConnect, with stable source/target tags, duplicate checks, durable item-level receipts, retry, and mandatory sync.
- GitHub CI, setup instructions, extension boundaries, and a release checklist are included for personal forks.

## Safe defaults and migration

- Existing connection settings continue to load.
- Journal AI and English-to-Anki are off by default. Enable either under Worker Status → Processing only after its local dependency is ready.
- Workout and Food remain MongoDB-only; v0.6.0 does not invent an external destination for them.
- MongoDB remains the packaged production database. Store ports are injectable for a fork, but there is no runtime database plug-in loader.

## Verification evidence

- Automated: 256 tests passed; Web/Desktop type checks, ESLint, Web production build, Rust release build, and NSIS packaging passed locally on Windows.
- Manual still required: installed keyboard/focus behavior, historical session selection, long-page scrolling, iPhone cross-device sync, Codex login, AI-organized Heptabase append, real AnkiConnect add/sync, and production deployment.

## Known limitations

- The Windows installer is unsigned.
- Heptabase append does not expose an idempotency key; a crash after append but before Cloud acknowledgement can require duplicate inspection.
- Anki note generation has no application-level daily limit and uses the structured `English_AI` model.
- Authentication remains intentionally single-user.
